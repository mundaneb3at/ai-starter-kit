# Frustrations

_Lives at `work\FRUSTRATIONS.md`. Personal: keep it out of any repo you push (the kit's
`.gitignore` already lists it). One row per thing that keeps going wrong, slowing you down, or
that you wish worked. The point is not the list, it is the **Fix / proof** column: things that
were already solved get raised again when nothing shows the fix._

**How the AI uses this file.** When the user sounds frustrated, or says "note that", "this keeps
happening", "I wish": (1) search this table first, dedupe before adding; (2) if a matching row
exists, read out its Fix column instead of starting over; (3) if it is new, **ask before
writing**, one question, with the proposed row shown: "Add this to FRUSTRATIONS.md? [row]". Never
append silently. Nothing medical, financial or about other people goes here; that belongs in
`private\`.

Status is one of: `open` · `fixed` (Fix column says how) · `won't fix` (say why) · `recurring`
(fixed before, back again: the old fix did not hold, look at why).

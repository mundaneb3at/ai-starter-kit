# Verify before done

**Use when** you are about to say "done," commit changes, or hand work back. A
false "done" costs far more than an honest "not yet."

## Steps

1. **Write down what "done" means** for this task — the acceptance criteria.
2. **Actually run / test it.** Don't assume it works because it looks right.
3. **Check the edges**: empty input, the boundary case, and whether you broke
   anything next to what you changed.
4. **Report honestly.** State what is *verified*, what is *untested*, and what is
   *known to be incomplete or broken*.

## The rule

"Needs manual verification" is a valid, honest status — say it when it's true.
A confident "done" on untested work is not acceptable.

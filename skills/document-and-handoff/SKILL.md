# Document and handoff

**Use when** you finish a unit of work, pause for the day, or make a decision
worth remembering. Chat scrolls away; a file persists and can be searched.

## Steps

1. **Summarize the change** in a short block: *what* changed, *where* (file
   paths), and *why*.
2. **Record decisions and their reasons** — so nobody (including future-you)
   relitigates a settled choice.
3. **Note what's left**: the next step, any open question, anything blocked.
4. **Save it next to the work** — a `NOTES.md` in the project folder, or a dated
   handoff file — not only in the chat window.

## Why it matters

A two-minute written handoff turns "where was I?" at the start of the next
session into "pick up at step 3." It is the cheapest productivity win available.

## Avoid

- Leaving the only record of a decision inside a chat transcript.
- Writing a handoff so thin the next session has to re-discover the context.
